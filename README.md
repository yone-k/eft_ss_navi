# EFT Screenshot Navi

[![CI](https://github.com/yone-k/eft_ss_navi/actions/workflows/ci.yml/badge.svg)](https://github.com/yone-k/eft_ss_navi/actions/workflows/ci.yml)

Escape from Tarkov（EFT）が生成するスクリーンショットの**ファイル名**から現在座標とカメラ方向を読み取り、マップ上へ最新位置を表示するWindowsアプリです。

スクリーンショット画像の内容、ゲームプロセス、ゲームメモリ、入力にはアクセスしません。グループに未参加の間はネットワーク通信を行いません。

## 主な機能

- EFTのスクリーンショットを監視し、現在位置と向きをマップ上へ表示
- 9種類の校正済みマップを同梱
- PMC脱出、共同脱出、SCAV脱出、Transit、PMCスポーンを表示
- マップの拡大・縮小、移動、全体表示、90度単位の回転
- 最大5人のグループで、選択マップと各メンバーの最新位置を共有
- 手持ちのマップ画像を追加して3地点で校正
- 監視先、マップ設定、最後に選択したマップをローカルへ保存

## 動作環境

- Windows 11 x64
- [.NET 10 Runtime（x64）](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Windows App SDK Runtime 2.4（x64）](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)
- [Microsoft Visual C++ Redistributable（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe)

Windows 10、Windows on ARM、x86、MSIX、インストーラー、単一EXEには対応していません。

## インストールと起動

1. 必要なランタイムをインストールします。
2. GitHub Releasesから配布ZIPをダウンロードして展開します。
3. `EftSsNavi.App.exe`を起動します。

アプリ本体だけを別の場所へ移動せず、展開したファイル一式を同じフォルダーに置いたまま起動してください。

## 初回設定

1. アプリを起動します。
2. `%USERPROFILE%\Documents\Escape from Tarkov\Screenshots`が存在する場合、自動的に監視を開始します。
3. 既定フォルダーが存在しない場合、上部の「監視先」にある［変更］からEFTのスクリーンショットフォルダーを選択します。
4. 上部の「現在のマップ」からプレイ中のマップを選択します。

監視先を変更すると、それまで表示していた位置は消去されます。監視開始前から存在する画像は処理せず、切り替え後に作成された次の有効なスクリーンショットを待ちます。

## 同梱マップ

次の校正済みマップを選択するだけで利用できます。

- Customs
- Factory
- Ground Zero
- Interchange
- Lighthouse
- Reserve
- Shoreline
- Street of Tarkov
- Woods

同梱マップでは、右側の凡例に従ってPMC脱出、共同脱出、SCAV脱出、Transit、PMCスポーンも表示します。マップ画像と地点データの出典・ライセンスは[`THIRD-PARTY-NOTICES.md`](src/EftSsNavi.App/THIRD-PARTY-NOTICES.md)を参照してください。

## 現在位置を表示する

1. 「現在のマップ」からプレイ中のマップを選択します。
2. EFTで新しいスクリーンショットを撮影します。
3. 有効なファイル名を検出すると、現在位置と向き、`X, Y, Z`、処理したファイル名を表示します。

マウスホイールで拡大・縮小、左ドラッグでマップを移動できます。［マップ全体を表示］で画像全体へ戻り、左右の回転ボタンでマップを90度ずつ回転できます。回転状態はマップごとに保存されます。

マップ切替、監視先切替、選択中マップの削除、アプリ再起動では古い位置を復元しません。切り替え後または起動後の次の有効なスクリーンショットを待ちます。

## グループで位置を共有する

1. ツールバーの［グループ］を開き、16文字以内の表示名を入力します。
2. ホストは［ホストとして開始］を押し、4文字区切りで表示された16文字のルームコード（例: `ABCD-EFGH-JKLM-NPQR`）を信頼できるメンバーへ共有します。
3. 参加者は同じ画面でルームコードを入力し、［参加］を押します。
4. 接続後は、各自がEFTでスクリーンショットを撮るたびに最新位置と向きが共有されます。セッションを離れるときは［退出］、ホストが終了するときは［セッションを終了］を押します。

接続確立時だけ、開発者がCloudflare Workers上に用意したシグナリングサーバー（`https://eftssnavi-signaling.eftssnavi-signaling-worker.workers.dev`）とSTUNサーバー（既定はGoogle）へ通信します。シグナリングサーバーはCloudflareの無料枠で運用しているため、無料枠の停止や上限超過時は新規接続とコード再発行ができなくなる場合があります。確立済みのWebRTC接続は影響を受けません。位置データはシグナリングサーバーを通らず、WebRTCで参加者間を直接送受信します。

シグナリングサーバーを通る接続情報はルームコード由来の鍵で暗号化されます。ただし、ルームコードを知っている人は誰でも参加でき、接続情報も復号できます。コードが漏洩すると、IP候補の取得、共有位置の閲覧、偽位置の送信、参加枠の占有が可能になるため、信頼できる相手だけに共有してください。Cloudflareの基盤は接続元IPアドレスなどの接続メタデータを処理しますが、このアプリ用Workerはこれらをログへ出力しません。TURNリレーは使用しないため、シンメトリックNAT同士など一部回線の組み合わせでは接続できない場合があります。

自前のシグナリングサーバーへ切り替える場合は、`workers/signaling/` を自分のCloudflareアカウントへデプロイし、`settings.json` の `SignalingWorkerUrl` に発行されたHTTPSベースURLを設定してください。Worker URLの設定画面はありません。

## 手持ちのマップ画像を追加する

PNG、JPEG、WebP形式の画像を追加できます。

1. ［マップを追加］を押し、識別しやすい名前を入力します。大文字・小文字だけが異なる同名マップは追加できません。
2. マップ画像を選択します。
3. EFTで離れた地点へ移動し、スクリーンショットを撮影します。
4. アプリが位置を検出したら、同じ地点をマップ上でクリックします。
5. 別の地点で同じ操作を繰り返し、合計3地点を指定します。

校正点には、互いに離れた識別しやすい地点を選んでください。重複または同一直線上になる組み合わせでは校正を確定できません。3地点校正では、元画像の局所的な歪みや地点選択の誤差までは補正できません。

手動追加したマップで位置がずれている場合は［位置を補正］を使えます。表示された校正点から置き換える点を選択し、現在位置マーカーを正しい場所へドラッグして、プレビューを確認してから［補正を確定］を押します。同梱マップではこの機能は表示されません。

［マップを削除］は保存したマップ設定と校正情報だけを削除し、元の画像ファイルは削除しません。

## マップ画像の再検証

手動追加したマップを選択すると、次の情報を校正時の値と照合します。

- 画像の絶対パス
- 画像の幅と高さ
- 画像内容のSHA-256

いずれかが一致しない場合は校正を無効として位置を表示しません。変更した画像を使う場合は、現在のマップ設定を削除して追加し直してください。

## 設定とプライバシー

設定は次のファイルへ保存します。

```text
%LOCALAPPDATA%\EftSsNavi\settings.json
```

保存する情報は、監視ディレクトリ、マップ設定、校正点、最後に選択したマップ、グループ表示名、シグナリングサーバーURL、STUNサーバー設定です。ルームコード、参加者一覧、位置履歴、スクリーンショット画像、ゲームアカウント情報は保存しません。選択したスクリーンショットやマップ画像をコピー、移動、削除することもありません。

グループ参加中に送信する情報は、参加者ID、表示名、ワールド座標、水平前方ベクトル、観測時刻、選択マップ名だけです。スクリーンショット画像、ファイル名、ゲーム内時刻、連番、クォータニオン、監視ディレクトリのパスは送信しません。

読込不能な設定ファイルを検出した場合、アプリはそのファイルを自動上書きせず、画面上へエラーを表示します。
