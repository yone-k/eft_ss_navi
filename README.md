# EFT Screenshot Navi

[![CI](https://github.com/yone-k/eft_ss_navi/actions/workflows/ci.yml/badge.svg)](https://github.com/yone-k/eft_ss_navi/actions/workflows/ci.yml)

Escape from Tarkov（EFT）でスクリーンショットを撮ると、現在位置と向きをマップ上に表示するWindowsアプリです。最大5人のグループで位置を共有できます。

スクリーンショット画像の中身やゲームプロセスにはアクセスしません。

## まず使ってみる

1. 下記の「動作環境」にある3つのランタイムをインストールします。
2. [GitHub Releases](https://github.com/yone-k/eft_ss_navi/releases)から配布ZIPをダウンロードし、展開します。
3. 展開したフォルダー内の`EftSsNavi.App.exe`を起動します。
4. 上部の「現在のマップ」から、プレイ中のマップを選びます。
5. EFTでスクリーンショットを撮ります。
6. 検出された現在位置と向きがマップ上に表示されます。

EFT標準のスクリーンショットフォルダーが見つからない場合は、上部の「監視先」にある［変更］からフォルダーを選択してください。

> 初回起動時にWindows Defender ファイアウォールの確認が表示された場合は、グループ共有を利用するネットワークで通信を許可してください。

## グループで位置を共有する

### ホスト

1. ツールバーの［グループ］を開きます。
2. 表示名を入力して［ホストとして開始］を押します。
3. 表示されたルームコードを、一緒にプレイするメンバーへ伝えます。

### 参加者

1. ツールバーの［グループ］を開きます。
2. 表示名とホストから受け取ったルームコードを入力します。
3. ［参加］を押します。

接続後は、各メンバーがスクリーンショットを撮るたびに最新位置と向きが共有されます。離れるときは［退出］、ホストが終了するときは［セッションを終了］を押してください。

ルームコードを知っている人はグループへ参加できるため、信頼できるメンバーだけに共有してください。ルームコードはホストするたびに新しく発行されます。

## マップを操作する

- 拡大・縮小: マウスホイール
- マップを移動: 左ドラッグ
- 全体を表示: ［マップ全体を表示］
- 90度回転: 左右の回転ボタン

回転状態はマップごとに保存されます。マップや監視先を切り替えた後は、次に撮影したスクリーンショットから位置が表示されます。

## 利用できるマップ

次のマップは設定不要で利用できます。

- Customs
- Factory
- Ground Zero
- Interchange
- Lighthouse
- Reserve
- Shoreline
- Street of Tarkov
- Woods

同梱マップでは、PMC脱出、共同脱出、SCAV脱出、Transit、PMCスポーンも表示します。

## 手持ちのマップ画像を追加する

PNG、JPEG、WebP形式の画像を追加できます。

1. ［マップを追加］を押して、名前と画像を選びます。
2. EFTでスクリーンショットを撮ります。
3. 現在位置に対応する地点を、追加したマップ上でクリックします。
4. 離れた3地点で同じ操作を繰り返します。

位置がずれている場合は［位置を補正］から校正点を調整できます。［マップを削除］を押しても、元の画像ファイルは削除されません。

## うまく動かないとき

- 位置が表示されない: 監視先と選択中のマップを確認し、アプリ起動後に新しいスクリーンショットを撮ってください。
- グループへ接続できない: ルームコードを確認し、Windows Defender ファイアウォールで通信が許可されているか確認してください。
- 一度で接続できない: ［退出］後、もう一度ホストまたは参加を試してください。
- 特定の回線同士で接続できない: ネットワーク環境の組み合わせによっては、直接接続できない場合があります。

## 動作環境

- Windows 11 x64
- [.NET 10 Runtime（x64）](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Windows App SDK Runtime 2.4（x64）](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)
- [Microsoft Visual C++ Redistributable（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe)

アプリ本体だけを別の場所へ移動せず、展開したファイル一式を同じフォルダーに置いたまま起動してください。

Windows 10、Windows on ARM、x86、MSIX、インストーラー、単一EXEには対応していません。

## プライバシー

- スクリーンショット画像の内容、ゲームプロセス、ゲームメモリ、入力にはアクセスしません。
- グループに参加していない間は、グループ共有のための通信を行いません。
- グループでは表示名、選択中のマップ、現在位置と向きがメンバー間で共有されます。
- ルームコード、参加者一覧、位置履歴は保存しません。
